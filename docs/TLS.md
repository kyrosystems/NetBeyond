# Встроенный TLS

HTTPS-запросы используют статически собираемый Mbed TLS 3.6.6: commit `0bebf8b8c7f07abe3571ded48a11aa907a1ffb20`. Лицензия Apache-2.0 OR GPL-2.0-or-later; выбираем Apache-2.0. Это сторонний криптографический компонент на C, не собственная криптография NetBeyond. WinHTTP остаётся только для обычного HTTP, причём авто-редиректы выключены, чтобы HTTPS не проходил через SChannel.

Для проверки цепочки сначала читается `cacert.pem` рядом с exe. Если файла нет, корневые сертификаты импортируются из Windows ROOT в Mbed TLS. Имя хоста передаётся в `mbedtls_ssl_set_hostname`; peer verification обязателен. На XP ROOT может быть устаревшим; используйте проверенный актуальный CA bundle. Нельзя отключать проверку сертификатов ради открытия сайта.

Ограничения: TLS handshake и запуск на XP не проверены; HTTP/1.1 поверх TLS пока не поддерживает chunked, gzip, redirects и HTTP/2. Даже успешный TLS 1.3 не означает поддержку современных сайтов без CSS/JS/DOM. Сборка зависимости требует Git и framework submodule; Windows CI сможет выявить compile/link ошибки, но не доказывает работу на XP.
